
# Eventhub – Campus Event Management Platform

## Problem Statement

Develop a web application that enables students to discover, register for, and track college events while allowing organizers to manage events and participants.

## Key Features

### Student Portal
- Browse upcoming college events and view event details.
- Register for events and manage registrations.
- Search and filter events by category and date.
- View registered events through a personal dashboard.
- Access QR-based event passes.
- View announcements, activity points and event reviews.
- Track events through a calendar.

### Organizer Portal
- Create, edit, publish and delete events.
- Manage event registrations and participant details.
- Track event capacity and registration statistics.
- Verify attendance using QR codes or manual check-in.
- Publish announcements and view event analytics.


## Technology Stack
React · TypeScript · Tailwind CSS · Supabase
