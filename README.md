Problem Statement Name: College Event Management Platform

Problem Statement:

Develop a web application that allows students to discover, register for, and keep track of various events happening in their college.

The platform should also provide organizers with the ability to create, manage, and monitor their events and registrations.

⚙️ Core Requirements:

Your application should include the following functionalities:

1. Event Listing: Display upcoming college events with their names, descriptions, dates, venues and other relevant details.

2. Event Registration: Allow students to register for events through the platform.

3. Search & Filter: Enable users to search for events and filter them based on categories such as technical, cultural, sports, workshops, etc.

4. Organizer Dashboard: Provide organizers with the ability to create, edit and delete events.

5. Participant Management: Display the number of registered participants for each event and allow organizers to view the registration details.

6. Database Integration: Store event details and student registration information in a database.
